# Car-Insurance-Claim-Prediction
To predict whether a car insurance policyholder will file a claim in the next six months using various classification models and to evaluate the models’ ability to detect claims despite class imbalance.

---

Key Models Used:
- Logistic Regression  
- LASSO Logistic Regression  
- Ridge Logistic Regression  
- Random Forest

---

Evaluation Strategy:
- Accuracy, Sensitivity, Specificity, Precision, F1 Score, Balanced Accuracy, AUC  
- Threshold tuning from 0.1 to 0.9  
- Feature importance analysis included for Random Forest

---
